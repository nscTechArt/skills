# 虚化动词替换表

以下写法把动作包装成名词。必须改为直接动词。

| 不得使用 | 改写为 |
|---|---|
| 对 X 进行修改 / 处理 / 检查 | 修改 / 处理 / 检查 X |
| 实现 X 功能 | 增加 X；或写出 X 的具体行为 |
| 予以 X / 加以 X | X |
| 做好 X 工作 | X |
| 完成 X 的操作 | X |
| 将会 X | 会 X |
| 进行 X | X |
| 作出 X 决定 | 决定 X |
| 通过 X 的方式 | 用 X |
| 存在 X 问题 | 写出具体现象 |
| 有一定的 X | 写出具体的量；没有量时删除 |

「处理」本身也是虚化动词。能写出具体动作时，不用「处理」。
